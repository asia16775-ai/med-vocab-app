⚠️ กด ล้างข้อมูล Test หลังทดสอบเสร็จ — จะล้าง session_logs + ความคืบหน้า + ปิด test mode ของนิสิตคนนั้นในครั้งเดียว

🔄 Reset ความคืบหน้ารายคน

ล้าง study_start_date และ completed_days ของนิสิตที่เลือก — นิสิตจะเริ่มวันที่ 1 ใหม่

🔄 Reset ความคืบหน้าทุกคน

ล้าง study_start_date และ completed_days ของทุกคน — ทุกคนเริ่มใหม่จากวันที่ 1

🗑️ ล้างข้อมูล Session Logs

ลบประวัติการตอบทั้งหมด — ใช้เมื่อต้องการเริ่มเก็บข้อมูลวิจัยใหม่

⚠️ ควร Export CSV ก่อนกดปุ่มนี้เสมอ

💥 Full Reset — เริ่มวิจัยใหม่ทั้งหมด

ล้างความคืบหน้า + Session Logs ของทุกคนในครั้งเดียว

⚠️ ใช้เฉพาะก่อนเริ่มวิจัยรอบใหม่เท่านั้น — กู้คืนไม่ได้เด็ดขาด
